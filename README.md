# stealthnet.software

Сайт и документация панели [STEALTHNET SOFTWARE](https://github.com/STEALTHNET-APP/stealthnet-software).

Обычная статика: ни сборки, ни зависимостей — GitHub Pages отдаёт файлы как есть.
Поправить страницу можно прямо в веб-редакторе GitHub.

## Устройство

```
index.html      витрина
docs/           документация
assets/         стили, скрипт, индекс поиска
CNAME           домен для GitHub Pages
```

## Как менять

Правьте HTML напрямую — этого достаточно.

Если меняете сразу несколько страниц или добавляете новую, удобнее через генератор:
тексты лежат в `content.py`, шаблон (шапка, оглавление, подвал) — в `build.py`.

```bash
python3 build.py
```

Он пересобирает страницы и индекс поиска. Готовый HTML коммитится в репозиторий,
поэтому запускать его при каждой правке не обязательно.

## Правило про содержимое

Документация описывает то, что панель действительно делает. Если поведение изменилось,
правьте и здесь: устаревшая документация хуже её отсутствия — по ней принимают решения.
