# Interface gallery / Галерея интерфейсов

These are the project's real application screenshots, supplied by the [software repository gallery](https://github.com/STEALTHNET-APP/STEALTHNET-SOFTWARE/tree/main/docs/media). Names, addresses, measurements and plans are sanitized demonstration data. No production statistics, customer access codes or service credentials are shown. Mini App screenshots show the real `/app/` interface with a local test Telegram bridge; native Telegram chrome is not included.

Снимки настоящего интерфейса проекта получены из демонстрационной галереи основного репозитория. Имена, адреса, показатели и тарифы — тестовые данные. Пользовательские коды и секреты не показаны. Mini App снят с реального интерфейса `/app/` с тестовым мостом Telegram, без нативного окна приложения.

Each image has an origin sidecar. Images retain the [project license](../../LICENSE). Website typography uses local Onest under [SIL OFL](../fonts/OFL.txt). The application's pictured fonts retain their own licenses in the software repository.
