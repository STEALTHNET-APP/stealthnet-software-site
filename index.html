Connect over SSH to a clean Debian or Ubuntu server as root. The installer downloads the latest stable release and guides you through setup.

Requirements and full installation guide
Install from GitHubbash
apt-get update
apt-get install -y git curl ca-certificates
git clone --depth 1 https://github.com/STEALTHNET-APP/STEALTHNET-SOFTWARE.git /root/stealthnet-installer
cd /root/stealthnet-installer
bash install.sh
