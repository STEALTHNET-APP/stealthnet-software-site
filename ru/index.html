со своего сервера.

Подключитесь по SSH к чистому серверу Debian или Ubuntu как root. Установщик скачает актуальный стабильный релиз и проведёт через настройку.

Требования и все шаги установки
Установка через GitHubbash
apt-get update
apt-get install -y git curl ca-certificates
git clone --depth 1 https://github.com/STEALTHNET-APP/STEALTHNET-SOFTWARE.git /root/stealthnet-installer
cd /root/stealthnet-installer
bash install.sh
