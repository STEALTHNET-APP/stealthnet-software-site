Быстрый старт

За один проход: поднять панель, создать профиль конфигурации, подключить ноду, выдать клиенту подписку и убедиться, что она работает.

Что понадобится

  • Сервер с Debian 12 или Ubuntu 22.04+, root-доступ.
  • Домен для панели и отдельный домен для подписок — их A-записи должны указывать на сервер.
  • Токен телеграм-бота, если продажи идут через бота.
Почему подписки на отдельном домене. Если домен панели заблокируют, клиенты продолжат обновлять конфиги: сервис подписок работает независимо и умеет жить на другом сервере, имея только ключ доступа к API.

Установка

git clone https://github.com/STEALTHNET-APP/stealthnet-software.git
cd stealthnet-software
cp .env.example .env

В .env заполните адреса панели и подписок, доступ к базе и токен бота. Затем:

docker compose up -d
docker compose logs -f api

В логе появится строка с логином и одноразовым паролем первого администратора. Смените пароль сразу после входа.

Профиль конфигурации

Профиль — это конфиг Xray, который раздаётся нодам. Один профиль обслуживает много нод: клиентов в него вписывает агент на месте.

  1. Откройте Инфраструктура → Профили конфигураций → Новый профиль.
  2. Выберите заготовку. Для начала — VLESS + Reality (TCP): она не требует ни своего домена, ни сертификата.
  3. Откройте редактор и замените поля, написанные заглавными буквами: ключи берутся кнопкой «Ключи Reality» на той же странице.
  4. Сохраните. Панель проверит конфиг настоящим движком и не даст сохранить нерабочий.
Плейсхолдеры вроде ВАШ_ПРИВАТНЫЙ_КЛЮЧ не пройдут проверку намеренно. Так о забытом поле становится известно сразу, а не от клиентов через неделю.

Первая нода

На странице Ноды нажмите «Подключить ноду». Панель выдаст готовую команду — выполните её на сервере ноды. Подробности и особые случаи: Ноды.

Через 15 секунд нода появится в списке зелёной. Если она красная — панель покажет причину прямо в строке.

Сквад и тариф

Сквад — это набор инбаундов, который выдаётся клиенту. Цепочка такая:

тариф → сквады → инбаунды → ноды
  1. Внутренние сквады → Создать сквад, отметьте инбаунды профиля.
  2. Тарифы → Новый тариф: код, название, срок и цена, лимит трафика и устройств, и сквады, которые получит клиент.

Хост

Хост — это строка, которую клиент увидит локацией в приложении. Он ссылается на инбаунд профиля и добавляет то, что знает только администратор: внешний адрес, порт, имя локации.

Хосты → Добавить хост: ремарка (например «🇩🇪 Франкфурт»), адрес и порт ноды, инбаунд. Порядок хостов в списке — это порядок локаций у клиента.

Первый клиент

Клиенты → Создать клиента. Укажите имя и тариф. В карточке, на вкладке «Подписка и VPN», будет ссылка — её и отдают клиенту.

Проверить, что всё сошлось, можно не выходя из панели: откройте ссылку в браузере — появится страница с приложениями под каждую платформу и кнопкой «Добавить подписку».

Ничего не отдаётся? Подписка не выдаёт конфиги, если у клиента нет активного срока, или ни один инбаунд его сквадов не поднят на живой ноде. Обе причины видны в разборе поломок.
